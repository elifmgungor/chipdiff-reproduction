# ChipDiff Reproduction

A Python reimplementation of:

Xu et al. (2008),
"An HMM approach to genome-wide identification of diffrential histone modification sites from ChIp-seq data."

##Goal 
1. Reproduce the origininal ChIPDiff method and ESST vs NPC H3K27me3 analysis.
2. Evaluate the assumptions and limitiations of the original method.
3. Explore possible methodlogical extensions.
