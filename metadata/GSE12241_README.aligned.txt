The included .aligned files contain the sequence data and their alignment 
coordiantes on the mouse reference genome (UCSC version mm8).

The format of each file is the same, in tab-delimited text:

<chromosome (mm8)>
<start of read (mm8)>
<end of read (mm8)>
<orientation of read (mm8)>
<unqiue read id: [flowcell].[lane].[id]>
<number of mismatches versus reference genome>
<read sequence>
